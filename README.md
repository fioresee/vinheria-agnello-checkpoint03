Vinharia Agnello - CP3 Web Development

Sobre o projeto: A Vinharia Agnello é um sistema de cadastro de vinhos que permite registrar informações, controlar o estoque e organizar os vinhos cadastrados. Nesse projeto, foram utilizadas funções de alta ordem (forEach, filter, reduce e map) para garantir uma melhor experiência do usuário. Ao usuário clicar no botão "Cadastrar vinho", ocorre um breve questionário sobre o nome, tipo, safra e estoque do vinho para que no fim ele apareça nos cards do site utilizando o push. Todas as informações podem ser vistas tanto pelo console quanto pelo alert.
